# Hospital Management System

A console-based Hospital Management System developed using Python. This project demonstrates Python fundamentals such as functions, modules, dictionaries, conditional statements, loops, and CRUD operations.

## Features

- Admin Login
- Patient Management (Add, View, Search, Update, Delete)
- Doctor Management (Add, View)
- Appointment Booking
- Bill Generation

## Technologies Used

- Python

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Run `main.py`.
4. Login using:
   - **Username:** `admin`
   - **Password:** `1234`
